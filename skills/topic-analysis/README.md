# topic-analysis — Topic analysis

[中文](README.zh-CN.md)

Breaks down a topic or claim from a strictly rational, neutral position in eight steps: identify the topic, reason step by step, analyse in depth, explain the causes behind it, add detail, correct common misconceptions, weigh the arguments for and against, and conclude.

The skill and the prompt are written in Chinese and answer in Chinese; the trigger phrases are Chinese too.

## Contents

| File | What it is |

## Usage

As a skill (claude.ai, the Claude app, or another assistant that supports Agent Skills):

1. Download the latest `topic-analysis-vYYYY.MM.DD.zip` from [Releases](https://github.com/walkwithedi/prompt-kit/releases) (it holds a `topic-analysis/` folder with `SKILL.md`).
2. Upload the zip on the Skills page of claude.ai settings and turn it on.
3. In a chat, say one of 「深度分析」「话题深度分析」「八步分析」「理性拆解一下」 and give the material to work on.

As a prompt: open [`prompt.md`](prompt.md), copy everything in the code block and paste it into any AI chat.

Both versions follow the same rules and are changed together.

# 话题深度分析

适用场景：按八个步骤理性客观地拆解一个话题或观点

用法：复制下面代码块里的全部文字，粘贴到任意 AI 对话框；需要材料的，把材料贴在「材料」一行后面再发送。

```text
角色定位：你现在扮演的是一个绝对理性和客观的个体，专注于逻辑分析和客观评估。

请基于下面的材料进行话题或观点的详细分析。

材料：

若材料为空，先用一句话问我要分析什么，不要自行设定话题。

分析步骤：

一、话题或观点识别：从所提供的信息中，明确需要分析的核心话题或观点。

二、逐步思考：按照逻辑顺序，逐步梳理和分析这个话题或观点，避免跳跃。

三、深度分析：在深入思考的基础上，一步步地审视和解构这个话题或观点。

四、背后理由：探究并阐述这个话题或观点产生的背景和根本原因。

五、细节补充：尽可能地给出这个话题或观点的更多细节和深入见解。

六、误解澄清：指出关于这些话题和观点的常见误解，并进行纠正。

七、论据分析：列举支持和反对这个话题或观点的主要论据。

八、分析总结：最后，基于以上步骤，总结分析过程和最终结论。
```

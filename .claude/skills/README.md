# Project skills

[中文](README.zh-CN.md)

Claude Code loads the skills in this directory in sessions on this repository. They are development aids only: the published skills live in the top-level skills/ directory, not here.

| Skill | Purpose | Upstream | Licence |
|---|---|---|---|
| grill-me | Type /grill-me to start an interview; calls grilling | [mattpocock/skills](https://github.com/mattpocock/skills) @ 49dd158 | MIT (LICENSE in the directory) |
| grilling | Interview about a plan or idea in rounds along its design tree, with a recommended answer per question | same | MIT (LICENSE in the directory) |

## Maintenance

- The contents match upstream and are not edited here; the LICENSE in each directory is copied from the root of the upstream repository.
- To update, copy the whole directory again from the upstream commit, keep the licence file and update the commit in the table. grill-me only calls grilling: update both together from the same commit.
